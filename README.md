# Tempo Task Manager 🚀

![unnamed](https://github.com/user-attachments/assets/668d25a8-a25a-45ad-b68c-33fe9d32e140)

Tempo — это умный менеджер задач на базе искусственного интеллекта, разработанный, чтобы помочь вам легко организовать свою жизнь. Созданный с использованием **React**, **TypeScript** и **Python (Flask)**, он использует возможности **Gemini AI** для помощи в декомпозиции задач, общения с вашими задачами и многого другого.

## ✨ Особенности

* **Умное управление задачами:** Создавайте, редактируйте, удаляйте и категоризируйте задачи.
* **AI-чат-бот:** Общайтесь со своими задачами! Спрашивайте у Gemini детали, советы или план выполнения.
* **Режим декомпозиции:** Автоматически разбивайте сложные задачи на управляемые подзадачи с помощью ИИ.
* **Кастомизация:** Выбирайте из красивых тем оформления (Светлая, Темная, Полночь, Лес) и пользовательских обоев.
* **Сохранение данных:** Ваши данные надежно сохраняются (Локальное хранилище для Гостей, SQLite для Пользователей).
* **Адаптивный дизайн:** Отлично работает как на ПК, так и на мобильных устройствах.

## 🛠️ Технологический стек

* **Frontend:** React, TypeScript, Vite, Tailwind CSS
* **Backend:** Python, Flask, SQLAlchemy, SQLite
* **ИИ:** Google Gemini API

## 🚀 Начало работы

Следуйте этим инструкциям, чтобы развернуть копию проекта на своем локальном компьютере.

### Предварительные требования

* Node.js (версии 18 или выше)
* Python (версии 3.8 или выше)
* Ключ API Google Gemini

### Установка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone [https://github.com/EkhsonK/Tempo-Task-Manager.git](https://github.com/EkhsonK/Tempo-Task-Manager.git)
    cd Tempo-Task-Manager
    ```

2.  **Настройка Frontend:**
    ```bash
    npm install
    # Создайте файл .env.local в корне проекта и добавьте ваш API ключ:
    # VITE_GEMINI_API_KEY=ваш_api_ключ_здесь
    npm run dev
    ```

3.  **Настройка Backend:**
    Откройте новый терминал и перейдите в папку backend:
    ```bash
    cd backend
    # Рекомендуется создать виртуальное окружение: python -m venv venv и активировать его
    pip install -r requirements.txt
    python run.py
    ```

4.  **Откройте ваш браузер:**
    Перейдите по адресу `http://localhost:3000` (или порту, указанному в вашем терминале для frontend).
